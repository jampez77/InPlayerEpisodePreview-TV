# Project images

`tv-logo.png` is original artwork generated with the built-in `image_gen` tool for this fork. It does not use the Jellyfin or upstream plugin logo.

Generation prompt:

> Use case: logo-brand. Asset type: original square GitHub project logo and Jellyfin plugin catalogue icon. Primary request: Create an elegant, memorable logo mark for an independent plugin called In Player Episode Preview — TV Edition. No lettering. A strong geometric symbol of three overlapping widescreen episode cards, the central screen containing a crisp play triangle, with subtle paired left/right navigation chevrons that suggest moving continuously through episodes. Give the mark a distinctive, balanced silhouette that stays readable at 64 pixels. Style: premium flat vector-like digital brand icon, precise shapes, restrained clean edges, no texture. Color palette derived from the app: bright ice cyan and soft blue accents against deep midnight navy. Centered composition with generous breathing room, square 1024x1024, solid navy background. Constraints: original artwork; no Jellyfin logo, no jellyfish, no borrowed brand marks, no words or letters, no mockup, no watermark, no extraneous decorative objects.

`tv-preview.png`, `tv-wrap-preview.png`, and `desktop-preview.png` are unmodified screenshots of the actual local demo using the built plugin, captured at 1280 × 720. The series, episode metadata, and landscape artwork are fictional demo content.

`logo.png`, `preview.gif`, and `expanded-view-side-by-side.png` are retained upstream assets from [Namo2/InPlayerEpisodePreview](https://github.com/Namo2/InPlayerEpisodePreview); they are not the TV edition's branding or current screenshots. The upstream MIT license remains in `LICENSE.md`.
